# Human-readable requirements follow the ISO/IEC/IEEE 29148 StRS

The human-readable requirements for this project are written as a Stakeholder Requirements Specification (StRS) as defined by ISO/IEC/IEEE 29148:2018, at `docs/requirements/stakeholder-requirements-specification.md`, with requirement IDs `StR-nnn` (matching the document abbreviation; a future SRS would use `SwR-nnn`). The more familiar name "User Requirements Specification" comes from regulated-industry practice (GAMP) and ISO/IEC 25065, which is usability-focused. Our requirements also cover offline operation, licensing, setup and platforms for stakeholders other than end users, which is the StRS's job. A more detailed Software Requirements Specification, if written later, sits beside it in `docs/requirements/` and traces back to the `StR-` IDs.
